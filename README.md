# BountyLab frontend study

This is a deliberately limited frontend prototype: application shell, dashboard,
Week 1 outline, and one interactive HTTP lesson. The remaining repository
components contain architecture guidance, not running services.

```sh
cd apps/web
npm ci
npm run dev
```

Open http://localhost:3000. See [the web prototype notes](apps/web/README.md)
for scope, validation commands, design decisions, and known limitations.

The platform architecture and persisted learning milestone remain described in
[ARCHITECTURE.md](ARCHITECTURE.md) and [PRODUCT_SPEC.md](PRODUCT_SPEC.md).
This study does not fulfill that backend milestone.
